# Employee Termination Trends - Brightness

This assignment uses employee records from Brightness, a hypermarket chain, to explore termination patterns and make a basic projection for 2021.

## Tasks

- Find the total number of employee terminations recorded in 2020
- Estimate 2021 terminations using different growth assumptions
- Compare termination counts by reason
- Group terminations into voluntary and involuntary categories
- Classify terminated employees by their length of service

## Workbook sheets

- `Data` — employee records used for the analysis
- `Questions` — case study instructions
- `Solutions` — worksheet for recording results
